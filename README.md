# 📌 Overview

**Social Saver** is a cross-platform video and audio downloader application developed using **Flutter and Dart**.

The application provides users with a simple and efficient way to download and save media content from supported social platforms. It focuses on providing a clean user interface, smooth user experience, and fast media processing.

The project was developed collaboratively by **Mubir Hussain** and **Alee Noor** as a software development project, combining UI/UX design, Flutter development, and cross-platform technologies.

# 🚀 Installation & Setup

## Prerequisites

Before running the project, install:

- Flutter SDK
- Dart SDK
- Android Studio / VS Code
- Git

Verify Flutter installation:

```bash
flutter doctor
```

---

## Clone Repository

```bash
git clone https://github.com/your-username/Social-Saver-A-cross-Platform-Video-Audio-Downloader.git
```

Navigate to project directory:

```bash
cd Social-Saver-A-cross-Platform-Video-Audio-Downloader
```

Install dependencies:

```bash
flutter pub get
```

Run application:

```bash
flutter run
```
